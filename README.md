Carteira 2040

Painel de acompanhamento da carteira de FIIs + Tesouro IPCA+ 2040.

Publicar no GitHub Pages
Crie um repositório (pode ser público — nenhum dado sensível vai no código).
Suba o index.html na raiz.
Settings → Pages → Source: Deploy from a branch → branch main, pasta / (root).
Em um ou dois minutos o painel está em https://SEU_USUARIO.github.io/NOME_DO_REPO/.
Cotações automáticas
Crie uma conta grátis em https://brapi.dev e copie o token.
Abra o painel → Ajustes → cole o token → Salvar ajustes.
O painel busca as cotações sozinho a cada 6 horas e no botão "Atualizar".
O IPCA acumulado em 12 meses vem da API do Banco Central (série 13522), sem token.

O token fica salvo no navegador, nunca no repositório.

Dados

Aportes e posições ficam no localStorage do navegador. Use "Baixar backup" de vez em quando.
